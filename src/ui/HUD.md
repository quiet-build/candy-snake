# HUD.ts

## Purpose

Documents src/ui/HUD.ts, a UI surface in this project. It defines HUD.

## Behavior

Defines the gameplay HUD chrome. Pause, lives, level, power-up, and score use warm-white surfaces with forest/cocoa text and restrained leaf/lilac/peach accents. On boards narrower than 400px, the level and power-up chips shift right to avoid the lives row; values, animations, and interactions remain unchanged.

## Maintenance

Update this companion when src/ui/HUD.ts changes in a way that affects public behavior, configuration, dependencies, data shape, or maintenance expectations.
