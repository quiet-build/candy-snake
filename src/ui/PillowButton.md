# PillowButton.ts

## Purpose

Documents src/ui/PillowButton.ts, a UI surface in this project. It defines PillowColor, PillowButtonOpts, makePillowButton.

## Behavior

Defines the shared two-layer cream-family button chrome. The existing color names remain the public options, while their faces use forest, peach, lilac, ochre, and warm white with a compact rounded radius. Press offsets, hit zones, breathing, and callbacks remain behaviorally unchanged.

## Maintenance

Update this companion when src/ui/PillowButton.ts changes in a way that affects public behavior, configuration, dependencies, data shape, or maintenance expectations.
