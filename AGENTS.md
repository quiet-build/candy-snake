## Companion Documentation

- Keep Markdown companion docs beside maintained source and config files, using the same basename with a `.md` extension.
- When a source or config file changes behavior, public contracts, dependencies, data shape, or maintenance expectations, update the matching companion doc in the same change.
- Do not add companions for generated, vendored, build-output, dependency, coverage, IDE state, or secret files.
